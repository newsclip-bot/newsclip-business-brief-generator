# newsclip-business-brief-generator

Create a short business briefing markdown from a category URL.

A lightweight script designed for simple pipelines.

## Why this exists
- Provide a simple starting point that can be expanded into a fuller tool.
- Make it easy to validate inputs and produce stable output formats.

## More from Newsclip
- [Newsclip](https://newsclip.com/)
- [Newsclip Editorial](https://newsclip.com/editorial/)
- [Newsclip Business](https://newsclip.com/business/)

## Usage
Example:

```bash
npm install
npm run start -- https://newsclip.com/business/
```

## Notes
- For production, you can swap the parsing layer with a robust library.
- Designed to be safe to run in CI or cron contexts.
